Pet World — تحديث يحافظ على التصميم الأصلي
============================================

هذه النسخة مبنية على ملف الموقع الأصلي (نفس الألوان الخضراء، الهيدر، كروت المنتجات، تفاصيل المنتجات، ماسح الباركود، ونموذج إدارة المنتجات). الإضافات فقط:
- مربعات الأقسام 3 في الصف بنفس ألوان التصميم الأصلي.
- تحديد موقع العميل إجباري عند إتمام الطلب.
- موقع العميل يظهر داخل لوحة الأدمن فقط، ولا توجد سياسة تسمح للزوار بقراءة الأوردرات أو إحداثيات العملاء.
- لوكيشن المحل عام ويظهر للجميع.
- قاعدة بيانات Supabase للمنتجات والأوردرات.
- دخول واجهة الأدمن بالباسورد فقط: petworld2025، كما طلبت. هذا قفل واجهة فقط وليس حماية قوية لبيانات Supabase.
- صوت عند وصول أوردر جديد واللوحة مفتوحة والأدمن مسجل دخول.

خطوات الإعداد:
1) أنشئ مشروعًا على https://supabase.com
2) من SQL Editor شغّل كامل ملف supabase_schema.sql.
3) من إعدادات المشروع انسخ Project URL والمفتاح العام anon/publishable إلى config.js. لا تستخدم service_role.
4) ملاحظة أمنية: الباسورد petworld2025 يحمي واجهة الأدمن فقط. صلاحيات قاعدة البيانات ما زالت تتطلب مستخدم Supabase بصلاحية admin. لا تضع بيانات حساسة أو تفتح صلاحيات قاعدة البيانات للعامة لمجرد أن شاشة الأدمن تطلب باسوردًا.
5) من Database > Publications أضف جدول orders إلى supabase_realtime حتى يعمل صوت الأوردرات.
6) ارفع index.html وconfig.js وsupabase_schema.sql وREADME_AR.md إلى جذر مستودع GitHub Pages.

ملاحظات مهمة:
- لا يمكن نشر قاعدة البيانات فعليًا من غير إنشاء مشروع Supabase ووضع بياناته؛ ملف config.js يأتي بقيم تجريبية فارغة عمدًا.
- المنتجات القديمة المحفوظة في localStorage لا تنتقل تلقائيًا إلى قاعدة البيانات. سجّل دخول الأدمن بعد الربط، ثم تأكد من استيراد/رفع المنتجات القديمة. لا تستبدل أي ملفات أو بيانات حية قبل أخذ نسخة احتياطية.
- الطلبات القديمة المحفوظة على متصفح واحد تظل في هذا المتصفح فقط، ولا يمكن استرجاع طلبات من أجهزة العملاء عبر localStorage.
- تنبيه الصوت يعمل عندما يكون الموقع مفتوحًا ولوحة الأدمن مسجلة الدخول. التنبيه أثناء إغلاق المتصفح يحتاج إشعارات Push وخدمة خلفية إضافية.
